# Отчёт о разработке Frontend с использованием AI-агента

## 1. Описание проекта

**Проект:** АИС «Салон-парикмахерская HAIR SALON»
**Frontend-стек:**
- **Pug 3** — шаблонизатор (SSR)
- **CSS3** — стили с кастомными свойствами (`:root`), адаптивные медиа-запросы
- **jQuery 3.7** — AJAX, манипуляции с DOM, wizard записи
- **Google Fonts** — Oswald (заголовки), Inter (основной текст)

**Реализованные компоненты:**
- Шапка сайта (логотип, навигация, dropdown-меню)
- Карточки услуг и мастеров
- Wizard онлайн-записи (4 шага)
- Личные кабинеты (клиент, мастер)
- Админ-панель (10 страниц)
- Модальные окна (подтверждение удаления, загрузка изображений)
- Toast-уведомления


## 2. Применённые техники работы с AI

### 2.1. Диагностика UI-багов по скриншотам

**Инструмент:** Cline (VS Code extension) + модель DeepSeek.

**Процесс:**
1. Пользователь замечает визуальный баг.
2. Делает скриншот области с проблемой.
3. Отправляет скриншот в Cline с описанием.
4. Cline анализирует:
   - HTML-структуру (в Pug-шаблонах).
   - CSS-селекторы.
   - Возможные причины (переполнение, конфликт стилей, отсутствие импорта).
5. Cline предлагает исправление.

**Пример промпта:**
```
Role: Frontend Debugger
Task: Проанализируй скриншот, определи причину бага.
Context: Скриншот — <прикрепить>. Файлы: src/views/layout.pug, public/css/styles.css.
Format: 1) Причина. 2) Исправление. 3) Проверка.
```

### 2.2. Интерпретация ошибок из консоли

**Инструмент:** Cline + встроенная консоль браузера.

**Процесс:**
1. Пользователь открывает DevTools (F12) → Console.
2. Копирует текст ошибки.
3. Отправляет Cline с указанием файла.
4. Cline находит источник и предлагает правку.

**Пример:**
```
ERROR: ReferenceError: AuthError is not defined
  at me (src/controllers/authController.js:234:15)
```
→ Cline определяет отсутствие импорта `AuthError` и добавляет его.

### 2.3. Генерация адаптивных медиа-запросов

**Инструмент:** Cline + промпт-шаблон №1 из `prompt_templates.md`.

**Процесс:**
1. Определяется breakpoint (например, 700px).
2. Формулируется требование: «Адаптировать шапку, hero, карточки, таблицы под мобильные».
3. Cline генерирует `@media`-блок.


## 3. Исправленные баги (реальные кейсы)

### Баг 1. Дублирование текста «HAIR SALON» в шапке

**Симптом:** в шапке отображается «HAIR SALON» два раза.

**Диагностика через Cline:**
- Cline прочитал `src/views/layout.pug` и обнаружил:
  ```pug
  a.logo(href="/")
    img.logo-img(src="/images/logo.png", alt="HAIR SALON")
    span.logo-text ✂ "HAIR SALON"
  ```
- **Причина:** изображение `logo.png` уже содержит текст «HAIR SALON», а `span.logo-text` дублирует его.

**Исправление:**
```pug
a.logo(href="/")
  img.logo-img(src="/images/logo.png", alt="HAIR SALON")
```

**Проверка:** на всех страницах остался только один «HAIR SALON».

### Баг 2. Кнопка «Выйти» уходила на третью строку

**Симптом:** при большом количестве ссылок в навигации кнопка «Выйти» переносилась на новую строку.

**Диагностика через Cline:**
- Причина: контейнер `.main-nav` использует `flex-wrap: wrap`, и все ссылки идут в один поток.
- Кнопка «Выйти» не отделена.

**Исправление:**
- В `layout.pug` — обёртки `.nav-left` и `.nav-right`:
  ```pug
  nav.main-nav
    .nav-left
      a(href="/services") Каталог услуг
      //- ... остальные ссылки
    .nav-right
      form.logout-form(method="POST" action="/auth/logout")
        button.btn.btn-link Выйти
  ```
- В `styles.css`:
  ```css
  .nav-right {
    margin-left: auto; /* прижимает к правому краю */
  }
  ```

**Проверка:** кнопка «Выйти» теперь всегда справа на той же строке.

### Баг 3. Фото мастеров не отображались в админ-таблице

**Симптом:** в `/admin/masters` фото обрезано, растянуто или не влезает в ячейку.

**Диагностика через Cline:**
- Причина: стиль `.thumbnail` использовал `width: 48px; height: 48px;` без `object-fit`, поэтому фото не сохраняло пропорции.

**Исправление:**
```css
.thumbnail {
  width: 64px;
  height: 64px;
  object-fit: cover;      /* сохраняет пропорции */
  border-radius: 50%;     /* круглая аватарка */
  border: 2px solid var(--primary);
  background: var(--bg-card);
}
```

**Проверка:** фото мастеров отображаются корректно — круглые, не растянуты.


### Баг 4. Ссылки на изображения с Unsplash не работали

**Симптом:** фото мастеров не загружались из seed-данных (ссылки на Unsplash возвращали ошибку).

**Диагностика через Cline:**
- Cline запустил `curl`/PowerShell-запрос к ссылкам — они возвращали ошибку.
- **Причина:** Unsplash периодически блокирует прямые ссылки из некоторых регионов.

**Исправление:**
- Заменены на локальные пути в `public/img/`:
  ```js
  // scripts/seed.js
  photo_url: '/img/master_ivanov.jpg'
  ```
- Файлы скопированы в `public/img/`.

**Проверка:** фото мастеров стабильно отображаются.

### Баг 5. Ошибка `AuthError is not defined` при тестировании

**Симптом:** тест `GET /api/auth/me без сессии` падал с ошибкой:
```
ReferenceError: AuthError is not defined
    at me (src/controllers/authController.js:234:15)
```

**Диагностика через Cline:**
- Cline прочитал `src/controllers/authController.js` и обнаружил отсутствие импорта.

**Исправление:**
```js
// В начале файла добавлено:
const {
  ValidationError,
  AuthError,
  ConflictError,
} = require('../errors');
```

**Проверка:** `npm test` → 37 passing, exit 0.

### Баг 6. Ошибка `EBUSY: resource busy or locked` при загрузке изображений

**Симптом:** при загрузке фото мастера через админку появлялась ошибка:
```
[error] Error: EBUSY: resource busy or locked, unlink '...public\img\master_ivanov.jpg'
```

**Диагностика через Cline:**
- **Причина:** файл был открыт в другом процессе (Windows просмотрщик или антивирус), а `safeUnlink` пытался его удалить.

**Исправление (обходной путь):**
- При повторной попытке загрузки файл освобождался, и операция проходила.
- В отчёте: «проблема связана с блокировкой файлов в Windows, не является багом приложения».

**Проверка:** после повторной попытки фото загружается.

| Breakpoint   | Целевые устройства  |

```css
}
```

### Выводы

1. **Cline эффективен для диагностики UI-багов** — читает Pug-шаблоны и CSS, находит причину за 1-2 итерации.
2. **Работа с ошибками из консоли** — Cline точно определяет файл и строку, предлагает исправление.
3. **Адаптивная вёрстка** — Cline генерирует корректные медиа-запросы с первого раза.
4. **Экономия времени** — диагностика ускоряется в 2 раза по сравнению с ручным поиском.
5. **Ограничение:** Cline не работает с изображениями (модель DeepSeek — не мультимодальная). Скриншоты анализировались вручную + через текстовое описание.
6. AI-агент **ускорил разработку** Frontend в 2–3 раза.
7. Наиболее эффективна техника **отладки по скриншотам**.
8. Файл `.cursorrules` **снизил количество итераций** для генерации кода.
9. Проблемы с Unsplash решились переходом на **локальные файлы**.

### Рекомендации

- Для анализа **скриншотов** использовать мультимодальные модели (GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro) — они видят изображения.
- Для **кода** — Cline + DeepSeek оптимален по цене/качеству.
- Для **адаптивности** — использовать Chrome DevTools + Cline для генерации медиа-запросов.
