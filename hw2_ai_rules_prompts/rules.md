# Файл системных правил AI-агента

## Для какого агента?

Файл `.cursorrules` предназначен для:
- **Cursor** — читает `.cursorrules` автоматически из корня проекта.
- **Cline** (VS Code) — правило подключается через настройки расширения или через файл `.clinerules` (симлинк на `.cursorrules`).
- **Aider** (CLI) — используется через `--read .cursorrules`.

Для универсальности файл размещён в корне проекта под именем `.cursorrules`.

## Структура файла

Файл содержит **12 разделов** и **>30 правил**, покрывающих все требования ДЗ:

|----|-------------------------------------|-------------------|

**Всего:** ~60 отдельных правил (суммарно по всем разделам).

## Ключевые запреты (примеры)

1. ❌ Не использовать `var` — только `const`/`let`.
2. ❌ Не использовать `mysql2` без `/promise`.
3. ❌ Не писать SQL без параметров `?` (защита от SQL-инъекций).
4. ❌ Не обращаться к БД из контроллеров — только через модели.
5. ❌ Не возвращать `password_hash` в API-ответах.
6. ❌ Не использовать `console.log` в production-коде.
7. ❌ Не менять матрицу `ALLOWED_TRANSITIONS` без явного запроса.
8. ❌ Не использовать TypeScript — только JavaScript (CommonJS).

## Ключевые обязательства (примеры)

1. ✅ Всегда использовать `withTransaction` для многошаговых операций.
2. ✅ Всегда проверять роли через `requireAuth` / `requireRole`.
3. ✅ Всегда возвращать ошибки в формате `{ error, message, details? }`.
4. ✅ Всегда валидировать входные данные через `src/utils/validators.js`.
5. ✅ Всегда писать JSDoc для экспортируемых функций.
6. ✅ Всегда использовать `try/catch + next(err)` в контроллерах.

## Как проверялось

Правила тестировались на реальных задачах ДЗ №1:
1. **Аудит проекта** — Cline следовал правилам стиля при чтении файлов.
2. **Исправление 11 несоответствий** — Cline следовал правилам в разделе «Границы» (не переписывал проект с нуля).
3. **Создание `formatPhone`** — Cline автоматически:
   - Изучил стиль через раздел 12 «Эталонные файлы».
   - Использовал JSDoc (правило 3.3).
   - Создал файл в правильном месте (`src/utils/phone.js`).
   - Следовал формату вывода (раздел 5).
