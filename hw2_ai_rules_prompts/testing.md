## Тестовая задача 1

**Название:** Функция `formatDuration(minutes)` — конвертирует количество минут в человекочитаемый формат.
**Зачем нужна:** в карточках услуг проекта «Салон-парикмахерская» вместо `90 мин` удобнее показывать `1 ч 30 мин`.
**Требования:**
- Принимает число минут (целое, ≥ 0).
- Возвращает строку:
  - `< 60` → `'45 мин'`
  - кратное 60 → `'2 ч'`
  - остальное → `'1 ч 30 мин'`
- При невалидном вводе (отрицательное число, не число) — возвращает `''`.

**Целевой файл:** `src/utils/formatDuration.js`.

## ❌ Вариант А — БЕЗ применения `.cursorrules`

Напиши функцию formatDuration(minutes), которая принимает количество минут
и возвращает строку вида "1 ч 30 мин" или "45 мин" или "2 ч".
Если число меньше 60 — только минуты. Если кратно 60 — только часы.
Иначе — часы и минуты. Если число невалидное — верни пустую строку.

### Ответ агента (raw)

```js
function formatDuration(minutes) {
  if (typeof minutes !== 'number' || minutes < 0) return '';
  var hours = Math.floor(minutes / 60);
  var mins = minutes % 60;
  if (hours === 0) return mins + ' мин';
  if (mins === 0) return hours + ' ч';
  return hours + ' ч ' + mins + ' мин';
}

module.exports = { formatDuration };
```

### Ответ агента (raw, с правилами)

```js
'use strict';

/**
 * Преобразует количество минут в человекочитаемый формат.
 *
 * Примеры:
 *   formatDuration(45)   → '45 мин'
 *   formatDuration(60)   → '1 ч'
 *   formatDuration(90)   → '1 ч 30 мин'
 *   formatDuration(0)    → '0 мин'
 *   formatDuration(-5)   → ''
 *   formatDuration('60') → ''
 *
 * @param {number} minutes — целое число минут (≥ 0)
 * @returns {string} строка вида '45 мин' / '2 ч' / '1 ч 30 мин' или '' при ошибке
 */
function formatDuration(minutes) {
  // Валидация: должно быть целым неотрицательным числом
  if (typeof minutes !== 'number' || !Number.isInteger(minutes) || minutes < 0) {
    return '';
  }

  const hours = Math.floor(minutes / 60);
  const restMinutes = minutes % 60;

  // Только минуты (меньше часа)
  if (hours === 0) {
    return `${restMinutes} мин`;
  }

  // Только часы (кратно часу)
  if (restMinutes === 0) {
    return `${hours} ч`;
  }

  // Часы и минуты
  return `${hours} ч ${restMinutes} мин`;
}

module.exports = { formatDuration };
```

> Context: Проект использует CommonJS. Стиль — см. `.cursorrules`.

```js
'use strict';

/**
 * Нормализует номер телефона к формату «+7 (XXX) XXX-XX-XX».
 * Принимает 10- или 11-значные номера, удаляет все нецифровые символы.
 * Если номер некорректен — возвращает исходное значение.
 *
 * @param {string} phone — входной номер в любом формате
 * @returns {string} нормализованный номер или исходное значение
 */
function formatPhone(phone) {
  if (typeof phone !== 'string') return '';
  const digits = phone.replace(/\D/g, '');
  const tenDigits = digits.length === 11 && (digits[0] === '7' || digits[0] === '8')
    ? digits.slice(1)
    : digits;

  if (tenDigits.length !== 10) return phone;

  return `+7 (${tenDigits.slice(0, 3)}) ${tenDigits.slice(3, 6)}-${tenDigits.slice(6, 8)}-${tenDigits.slice(8, 10)}`;
}

module.exports = { formatPhone };
```

- ✅ `'use strict'`
- ✅ `const` вместо `var`
- ✅ JSDoc-комментарий
- ✅ Валидация типа
- ✅ Обработка 10- и 11-значных номеров
- ✅ Единый стиль кода
- ✅ `module.exports`
- ✅ Понятные имена переменных
