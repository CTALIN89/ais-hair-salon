# Формулировка идеи

## 1. Название проекта

**АИС «Салон-парикмахерская HAIR SALON»** (внутреннее имя — *Salon Management System*).

## 2. Проблема, которую решает приложение

Салон-парикмахерская «HAIR SALON» (средний бизнес, 3–5 мастеров) сталкивается со следующими проблемами:

| Проблема               | Как проявляется                                                                  | К чему приводит                              |
|------------------------|----------------------------------------------------------------------------------|----------------------------------------------|
| Запись по телефону     | Администратор тратит 5–10 минут на один звонок, часто ошибается при выборе слота | Потеря времени, ошибки в расписании          |
| Двойные бронирования   | Два клиента записаны на одно время                                               | Недовольство клиентов, потеря репутации      |
| Отсутствие единой базы | Данные клиентов — в блокнотах и мессенджерах                                     | Невозможно вести историю посещений           |
| Сложность анализа      | Нет данных о загрузке мастеров и выручке                                         | Управленческие решения принимаются «на глаз» |
| Нет онлайн-записи      | Клиенты не могут записаться ночью или в выходной                                 | Потеря 20–30% потенциальных клиентов         |

## 3. Ценность продукта

**Для клиента:**
- Самостоятельная запись онлайн в удобное время (24/7).
- Прозрачный прайс-лист и свободные слоты мастеров.
- Возможность отменить/перенести запись без звонка.
- История своих посещений.

**Для мастера:**
- Личный кабинет с расписанием на день.
- Быстрая смена статуса записи (подтвердил → начал → завершил).
- Возможность указать фактическую стоимость услуги.

**Для администратора:**
- Единая база клиентов, мастеров, услуг.
- Управление расписанием и слотами.
- Отчёты по выручке и загрузке мастеров.
- Управление учётными записями и ролями.

## 4. Целевая аудитория

## 5. Ключевые функции (MVP)

**Реализовано **5 функции**:

| № | Функция                      | Описание                                                                                                                                |
|---|------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| 1 | **Онлайн-запись**            | 4 шага: услуга → мастер → дата → слот. Транзакционное создание записи со статусом `Created`.                                 |
| 2 | **Личный кабинет клиента**   | Активные записи + история. Возможность отменить или перенести запись.                                                                   |
| 3 | **Личный кабинет мастера**   | Расписание по дням, смена статусов (Confirmed → InService → Completed), ввод фактической стоимости.                                     |
| 4 | **Каталог услуг и мастеров** | Публичный просмотр без авторизации. Фильтрация по категории, поиск.                                                                     |
| 5 | **Админ-панель**             | CRUD для услуг, мастеров, пользователей, расписаний. Формирование отчётов (выручка, загрузка мастеров, история клиента). Экспорт в CSV. |

## 6. Стек технологий

- **Backend:** Node.js 18+ + Express 4 + mysql2/promise
- **БД:** MySQL 8.0
- **Frontend:** Pug 3 + ванильный CSS + jQuery 3.7
- **Аутентификация:** express-session + bcryptjs (cost 12)
- **Тесты:** Mocha + Chai + Supertest

## 7. Ограничения

- **152-ФЗ** — персональные данные клиентов не передаются во внешние сервисы.
- **Один сервер** — система разворачивается на VPS/локальном сервере.
- **Русскоязычный интерфейс** — все тексты, комментарии, JSDoc.

## 8. Параметры успеха

| Параметры                           | Целевое значение               |
|-------------------------------------|--------------------------------|
| Время записи онлайн                 | < 3 минут                      |
| Снижение нагрузки на администратора | −50% звонков                   |
| Двойные бронирования                | 0 (гарантируется транзакциями) |
| Охват клиентов онлайн-записью       | ≥ 60% |
