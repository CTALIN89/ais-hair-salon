# UI-концепции интерфейса

Для проекта «АИС Салон-парикмахерская HAIR SALON» сгенерированы **3 концепции интерфейса** с разными стилями дизайна:

| № | Название         | Стиль                    | Палитра         |
|---|------------------|--------------------------|-----------------|
| 1 | **Barbershop**   | Тёмный, брутальный       | Чёрный + золото |
| 2 | **Scandinavian** | Светлый, минималистичный | Белый + пастель |
| 3 | **Business Pro** | Корпоративный, строгий   | Синий + серый   |

Концепции различаются по:
- **Стилю дизайна** (цвет, типографика, визуальные акценты).
- **Компоновке элементов** (расположение карточек, форм, навигации).
- **Целевой аудитории** (мужская/женская/универсальная).


## Концепция 1: Барбершоп (тёмная, брутальная) — ✅ ВЫБРАНА

**Стиль:** тёмный фон (#121212), золотые акценты (#d4a54a), шрифты Oswald + Inter.
**Компоновка:** крупные карточки услуг, hero-баннер с CTA, липкая шапка.
**Особенности:**
- Кнопки золотые, при наведении темнеют
- Карточки услуг с крупной ценой
- Wizard записи в 4 шага

**Преимущества:**
- Соответствует тематике барбершопа
- Хорошая читаемость на тёмном фоне
- Запоминающийся бренд

**Недостатки:**
- Может не понравиться женской аудитории
- Требует тщательной настройки контраста


## Концепция 2: Минимализм (светлая)

**Стиль:** белый фон, серые акценты, шрифт Inter.
**Компоновка:** линейная сетка, много воздуха.

**Преимущества:** универсальность, чистота.
**Недостатки:** безликий, не отражает специфику салона.


## Концепция 3: Корпоративный (синий)

**Стиль:** синие тона, строгий дизайн, шрифт Roboto.
**Компоновка:** таблицы, формы в колонках.

**Преимущества:** солидность, подходит для бизнеса.
**Недостатки:** холодный, не подходит для сферы красоты.

## ✅ Обоснование выбора

Выбрана **Концепция 1 (Барбершоп)**, потому что:
1. Соответствует тематике (мужской + женский салон)
2. Золото + чёрный = премиум-восприятие
3. Соответствует бренду «HAIR SALON»
4. Высокий контраст для читаемости

### Альтернативы и почему они не подошли

**Минимализм:**
- Причина отказа: не отражает специфику барбершопа, не создаёт премиум-восприятия.
- Когда пригодилась бы: если салон перепозиционировался в женский бьюти-салон.

**Корпоративный:**
- Причина отказа: слишком холодный, не подходит для клиентского интерфейса.
- Когда пригодилась бы: для B2B-клиентов или отдельной админ-панели.
