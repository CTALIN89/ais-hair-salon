# Анализ требований проекта: «АИС Салон-парикмахерская HAIR SALON»

## 1. Описание задачи разработки

Разработка **веб-приложения** — автоматизированной системы управления салоном-парикмахерской. Система обеспечивает:
- каталог услуг и мастеров;
- онлайн-запись клиентов на услуги;
- личные кабинеты (клиент / мастер / администратор);
- управление расписанием мастеров и слотами времени;
- формирование отчётов (выручка, загрузка мастеров, история клиента);
- архивацию завершённых записей.

## 2. Технологический стек

| Шаблонизатор        | Pug 3                            |

## 3. Ключевые требования

| Категория               | Требование                                                                                                            |
|-------------------------|-----------------------------------------------------------------------------------------------------------------------|
| **Сложность**           | Средне-высокая: 18 таблиц БД, 3 роли, state machine статусов записи, REST API, ~40 JS-файлов                          |
| **Локальные файлы**     | Да — работа с 85+ файлами проекта (модели, контроллеры, шаблоны, тесты)                                               |
| **Безопасность данных** | **Критично** — персональные данные клиентов (ФИО, телефон, email), пароли (bcrypt), коммерческая тайна (прайс-лист,   | 
|                         |  отчёты по выручке)                                                                                                   |
| **Бюджет**              | Ограничен; приоритет бесплатным/недорогим решениям                                                                    |
| **Платформа**           | Windows, локальная разработка                                                                                         |
| **Задачи для AI**       | Генерация CRUD-кода, SQL-запросов, Pug-шаблонов, рефакторинг, исправление багов, написание тестов, аудит документации |

## 4. Ограничения и требования законодательства

- **152-ФЗ «О персональных данных»** — данные клиентов не должны передаваться в иностранные облачные сервисы без согласия субъекта.
- **Работа с локальными файлами** — 85+ файлов проекта, требуется контекст всего репозитория.
- **Бюджет** — приоритет решениям с бесплатным/дешёвым тарифом.
- **Локализация** — русскоязычный интерфейс и комментарии в коде.

## 5. Задачи, которые AI должен решать

1. Анализ структуры существующего проекта.
2. Поиск расхождений между документацией и кодом.
3. Генерация нового кода (функции, тесты).
4. Рефакторинг существующих модулей.
5. Проверка консистентности (запуск тестов, анализ вывода).
