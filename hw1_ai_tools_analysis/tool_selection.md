# Обоснование выбора AI-инструмента

## ✅ Выбранный инструмент: **Cline (VS Code extension) + DeepSeek-Coder**

## Ключевые факторы выбора

### 1. Безопасность данных (критично, 152-ФЗ)
Cline позволяет использовать **любого LLM-провайдера**, включая локальные модели через Ollama. Это даёт возможность **не передавать код проекта** (структуру БД с персональными данными клиентов) во внешние облака.

**Использованная конфигурация:** Cline + DeepSeek API. При необходимости легко переключается на `Ollama + deepseek-coder:6.7b` для полной изоляции.

### 2. Полный доступ к контексту проекта
Cline видит все 85+ файлов проекта, умеет:
- читать и редактировать файлы;
- запускать команды в терминале;
- анализировать вывод (тесты, git status);
- работать с diff перед изменениями.

### 3. Бесплатность
Сам Cline — бесплатное расширение VS Code. Стоимость использования = только токены LLM. При локальной модели через Ollama — полностью бесплатно.

### 4. Интеграция в рабочий процесс
Расширение встроено в VS Code — редактор, с которым я уже работал. Не нужно переключаться между окнами, поддерживается автодополнение и подсветка.

### 5. Совместимость с российскими реалиями
Cline можно подключить к **YandexGPT** через API — это отечественный провайдер, соответствующий требованиям 152-ФЗ.

## ❌ Альтернативы и почему они не подошли

| Инструмент         | Причина отказа                                                                               |
|--------------------|----------------------------------------------------------------------------------------------|
| **Bolt.new**       | (1) Не работает с существующим кодом; (2) передаёт данные в зарубежные облака (риск 152-ФЗ). |
| **Lovable**        | Аналогично Bolt.new — только прототипирование.                                               |
| **Replit Agent**   | Работа в браузере, ограничен доступ к локальным файлам.                                      |
| **Cursor**         | Мощный, но стоит $20/мес и требует отправки кода на серверы Cursor.                          |
| **GitHub Copilot** | Хорош, но облачный и платный.                                                                |
| **Gemini CLI**     | Уступает Cline по гибкости настройки провайдера.                                             |

## Итоговое обоснование

**Cline + DeepSeek-Coder** — оптимальный выбор для проекта, потому что:
1. ✅ Удовлетворяет требованию безопасности (152-ФЗ).
2. ✅ Имеет полный доступ к локальному проекту.
3. ✅ Бесплатный (при использовании локальной модели).
4. ✅ Умеет работать с терминалом, git, тестами.
5. ✅ Показал высокое качество работы на реальных задачах (см. `practice_report.md`).
