## Часть 2. Практическая задача: функция `formatPhone`

### Постановка задачи

**Промпт (RTCF):**
Role: Senior Node.js Developer
Task: Создай функцию formatPhone(phone) в файле src/utils/phone.js.
Context: Проект использует CommonJS ('use strict', module.exports).
Стиль: см. src/utils/validators.js (JSDoc, camelCase).
Функция принимает номер в любом формате (89001234567, +7 900 123-45-67, +79001234567).
Возвращает «+7 (900) 123-45-67».
При невалидном номере возвращает исходное значение.
Format: JSDoc-комментарий + module.exports.

### Что сделал Cline

1. **Прочитал `src/utils/validators.js`** — изучил стиль проекта.
2. **Создал `src/utils/phone.js`** с алгоритмом:
   - Отбрасывание нецифровых символов через `[^\d]`.
   - Нормализация по длине (10 / 11 цифр / иное).
   - Группировка в формат `+7 (XXX) XXX-XX-XX`.
3. **Самостоятельно исправил 3 неточности:**
   - Опечатку в морфологии JSDoc.
   - Уточнил `@returns` — функция может вернуть не только строку.
   - Переформулировал описание ветки «11 цифр», чтобы точно соответствовало реализации.
4. **Протестировал на 12 примерах** через `node -e "..."`.
5. **Проверил регрессию:** `npm test` → **exit 0** (37 существующих тестов проходят).
